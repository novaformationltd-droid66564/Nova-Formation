# Pixel Perfect Copy

اگر میں اپ کو ایک ویب سائٹ دوں تو کیا اپ اس کی کاپی ویب سائٹ بنا سکتے ہو اس کا اپ کو لنک دوں گا یو ار ایل دوں گا ویب سائٹ کا سیم پیجز ایچ ایوری تھنگ سیم بنانی ہے صرف ہوم پیج پہ اپ نے کچھ الگ ٹائپ کی جو ہے وہ اینیمیشنز اور چیزیں لگانی ہیں ٹھیک ہے اور تھیم سٹائل میں اپ کو دے دوں گا ریفرنس امیج میں ٹھیک ہے اور برینڈ برینڈنگ بھی میں اپ کو ریفرنس سمیٹ میں دے دوں گا اس پہ نمبر ہوگا ای میل ہوگا لوگو ہوگا اپ نے وہ ایگزیکٹ یوز کرنا ہے ٹھیک ہے لیکن جو اپ کو ریفرنس ویب سائٹ کا لنک دوں گا پیجز اپ نے سارے اسی ٹائپ کے بنانے ہیں سروسز ساری اپ نے وہی رکھنی ہے فارمز اسی طرح کے بنانے ہیں لے اؤٹ سٹائل اسی طرح کا بنانا ہے موبائل رسپانسو اور بوتھ ڈیسک ٹاپ رسپانسو اپ نے بنانی ہے لیکن ہر چیز اپ نے ویسے ہی رکھنی ہے بس اپ نے تھیم سٹائل تھیم کلر الگ رکھنا ہے اور ہوم پیج پہ کچھ چیزیں جو ہے وہ اپ نے ڈفرنٹ رکھنی ہے یعنی ہوم پیج اپ نے ایک مزید یونیک اور اچھے اینیمیشن کے ساتھ اس سے بھی پریمیم کوالٹی کی انیمیشن کے ساتھ اور اس سے بھی جو ہے وہ ہائی کوالٹی کی اینیمیشن کے ساتھ اپ نے بنانا ہے
